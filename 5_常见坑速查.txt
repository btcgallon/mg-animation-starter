说明：
- 这些是「代码制 MG 动画」这条路上最常见的坑，不针对任何风格。
- 每条按「现象 → 原因 → 处理」写，方便直接对照。
- 不同版本的工具命令可能略有差异；以 `--help` 为准。

----------------------------------------------------------------
A. 环境与安装
----------------------------------------------------------------

1. node: command not found
   现象：刚装完 Node，终端还是找不到。
   原因：PATH 没刷新，或装到了另一个 shell 的环境。
   处理：重开终端；仍不行就把 Node 安装目录加进 PATH。
         Windows 常见路径：C:\Program Files\nodejs

2. Node 版本太低
   现象：HyperFrames 启动报错，或 doctor 里 Node 是 fail。
   原因：版本低于 22。
   处理：升级到 Node 22 LTS 或更高，不要用旧版本硬跑。

3. ffmpeg: command not found
   现象：check 能过，render 失败；或退出码 0 但没有文件。
   原因：FFmpeg 没装，或不在 PATH。
   处理：安装 FFmpeg；或设置 HYPERFRAMES_FFMPEG_PATH /
         HYPERFRAMES_FFPROBE_PATH 指向绝对路径。

4. No such filter: 'setparams'
   现象：渲染报缺少 filter。
   原因：用了某个软件自带的精简版 FFmpeg。
   处理：换全量构建；验证：
         ffmpeg -hide_banner -bsfs | grep setparams
         ffmpeg -hide_banner -encoders | grep libx264

5. Chrome 红 / 启动超时
   现象：doctor 里 Chrome fail，或渲染卡在启动浏览器。
   原因：无头 Chrome 没下载、被杀软拦、或代理不通。
   处理：npx hyperframes browser ensure；
         设置 HTTPS_PROXY / HTTP_PROXY 后重试；
         不要用系统 Chrome 随便顶替，版本漂移会导致画面不一致。

6. npx 每次都很慢
   现象：每条命令都重新下载包。
   原因：没有全局安装。
   处理：npm install -g hyperframes@latest；
         或接受 npx 的缓存机制，不要频繁清缓存。

7. npm / pip 下载卡住
   现象：安装一直转圈或 TLS 报错。
   原因：网络 / 代理 / 镜像。
   处理：先问用户有没有代理；
         国内可临时用 registry.npmmirror.com（npm）
         或阿里云 PyPI 镜像（pip）；
         不要把镜像地址写死进项目。

----------------------------------------------------------------
B. 页面与渲染
----------------------------------------------------------------

8. 中文显示成方块
   现象：抽帧里全是 □□□。
   原因：字体没加载，或用了系统字体 / 在线字体。
   处理：把字体文件放进 assets/fonts/，用 @font-face 引用；
         检查文件名和 url 是否一致；
         渲染时不要依赖 Google Fonts。

9. 渲染时还在联网取资源
   现象：本机能看，换机器 / 断网就空白。
   原因：GSAP、字体、图片用了 CDN。
   处理：全部下载到本地 assets/，用相对路径引用。

10. 每帧画面都不一样
    现象：同一份代码，两次渲染结果不同。
    原因：动画里用了 Date.now()、Math.random()、setTimeout、
          网络请求、无限循环 CSS。
    处理：动画只依赖时间轴时间；随机数要固定种子；
          不要用 repeat: -1。

11. 页面一片空白 / 时间轴不动
    现象：snapshot 全黑或停在第一帧。
    原因：时间轴没注册，或根节点 data-* 写错。
    处理：确认根节点有 data-composition-id / data-duration /
          data-fps / data-width / data-height；
          确认 window.__timelines["<id>"] 已注册；
          确认主时间轴是 paused 的。

12. 元素该出现时不出现，或提前出现
    现象：空壳提前露出，或该显示时没有。
    原因：class="clip" 和 data-start / data-duration 没配对。
    处理：每个有时间范围的元素都要有这三个东西；
          新加的容器默认 opacity:0，到点再用 tl.set 显影。

13. 渲染内存爆 / 卡死
    现象：跑到一半 Chrome 崩，或系统很卡。
    原因：并发 worker 太多，每个 worker 都吃内存。
    处理：降低 worker 数；用 draft 画质；
          一次只跑一个整片；长片分段渲染再拼接。

14. 渲染退出码 0，但没有输出文件
    现象：命令说成功，目录里没有 mp4。
    原因：FFmpeg 不在 PATH，或输出路径写错。
    处理：检查 PATH / HYPERFRAMES_FFMPEG_PATH；
          用绝对路径输出；渲染后立刻 ffprobe。

15. C 盘临时目录爆
    现象：渲染中途磁盘满。
    原因：帧缓存默认在系统临时目录。
    处理：把帧缓存指到空间大的盘；
          定期清理 .hyperframes 的临时产物，但不要删历史记录。

16. z-index 怎么调都不生效
    现象：元素被盖住，加 z-index 没用。
    原因：父级有 transform，创建了新的层叠上下文。
    处理：先看父级有没有 transform / opacity / filter；
          调整 DOM 层级，而不是只加 z-index。

17. 数字滚动时整行跳位
    现象：计数动画把旁边的文字挤走。
    原因：数字宽度变化，flex / 居中布局跟着重排。
    处理：给数字固定宽度、右对齐，或放进固定尺寸容器；
          不要用 space-between 让数字参与分配。

18. 中文配音乱码 / 吞字
    现象：配音听起来像外语，或字被吃掉。
    原因：本地 TTS 的中文音素支持不好，或用了默认英文模型。
    处理：先合 3 句样音试听；不行就换 edge-tts 或别的本地 TTS；
          转写时显式指定 --model 和 --language zh，别用默认 small.en。
    补充：Windows 里 `python` 可能打开应用商店；用 `py -3` 或装官方 Python。

19. 60fps + 多 worker 渲出纯黑幕
    现象：成品能播放，但整段是黑的；单帧抽出来也黑。
    原因：高帧率 + 多并发时偶发的截图/缓存问题。
    处理：改用单 worker 或低内存模式重渲；
          出片后用 blackdetect 或抽帧验收，不要只看文件大小。

20. 新容器提前露空壳
    现象：还没到入场时间，边框 / 背景已经出现。
    原因：容器默认可见，只给子元素做了动画。
    处理：容器默认 opacity:0；到点用 tl.set 显示；
          检查每一屏的起始帧。

----------------------------------------------------------------
C. 流程与协作
----------------------------------------------------------------

21. 跳过逐屏静帧，直接写动画
    现象：动画做完发现构图不对，整片重渲。
    原因：把“能动”当成“排好了”。
    处理：先只排版、渲静帧、逐屏确认；
          静帧没过，不写动画。

22. 安全区靠眼估
    现象：字被平台 UI 遮住，或被裁掉。
    原因：没有量像素，凭感觉留边。
    处理：按平台规范 + 参考截图量出像素矩形；
          写进项目；检查时用像素扫描验证。

23. 改了时长 / 拍数，没重排 BGM
    现象：卡点全错，转场对不上鼓点。
    原因：只改了画面，没改音频。
    处理：改时长 = 重排 BGM；重新算拍点，重新对齐。

24. 页面里塞 audio，成品没声音
    现象：预览有声音，渲染出来是静音。
    原因：渲染器不一定帮你混页面里的音频。
    处理：先渲无声 MP4，再用 ffmpeg 混音；
          混完用 ffprobe 看有没有音轨。

25. 版本只靠 .bak 文件名
    现象：想回滚，回错版本。
    原因：文件名不可靠，备份可能被覆盖。
    处理：每版另存 index_v<版本>.html；
          回滚前先打开确认内容。

26. 用户给了参考图，还照理解重画
    现象：反复“不像”，改很多版。
    原因：没有按像素描摹。
    处理：先描轮廓 / 用矢量描摹工具；
          1px 对位验收；不要凭印象画。

27. check 通过就以为画面对
    现象：检查 0 error，但抽帧发现字太小 / 出框 / 空白。
    原因：check 是规则检查，不是审美检查。
    处理：一定要 snapshot 抽帧，逐张看；
          不能看图的模型，把 PNG 路径交给用户确认。

28. 出问题反复试同一招
    现象：同一个报错试了五次，还在原地。
    原因：没有定位根因。
    处理：贴完整报错；一次只改一个变量；
          两次不行就停下来报告，不要闷头重试。
